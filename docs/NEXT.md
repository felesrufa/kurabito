## 守ること

- データは端末内(localStorage)だけ。外部送信なし。CSP の `connect-src 'none'` を外さない
- 公開リポジトリなので、持ち主の家の事情がわかる初期値・テストデータを書かない
- ユーザー入力は `textContent` で表示する(innerHTML に入れない)
- データの形を変えたら `docs/DATA.md` を更新し、読み込み時の互換(古いバックアップ)を保つ
- 変更したら `sw.js` の `CACHE` と `app.js` の `VERSION` を上げる(上げないとiPhoneで古い版が残る)
- iPhoneのホーム画面アプリ(Safari)で使う前提。ボタンは押しやすい大きさに

## 預かりリスト(上から順に)

### 1. シチュエーション選び(大きい機能)

- 「備え」タブで、避難先(自宅避難/避難所/野営)× 季節(夏/冬)× 災害(地震/台風/津波/富士山噴火)を選ぶ
- 必要数と持っている数を突き合わせて、足りない分を出す(例:水 必要42L/ある32L → あと10L)
- 条件は持ち物ではなく**必要リストの側**に付ける。持ち物とはまとめ名で突き合わせる
- 必要数は「人数×日数」で自動計算し、手で上書きもできる(おむつは乳幼児の人数だけ、など)
- 家全体での最低個数(合計に対する判定)もここで扱う
- 必要リストの中身は、公的資料(東京備蓄ナビなど)を裏取りしてたたき台を作り、
  公的資料/体験談/自分メモの印を付ける。調べものが多いので、作る前に相談すること
