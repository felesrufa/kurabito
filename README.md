# kurabito

備蓄と日用品の在庫番。蔵人(くらびと)。

- **データは端末の中だけ。** アカウント登録なし、サーバーなし、外部への送信なし
- **個数制限なし・課金なし**
- **電波がなくても開ける**(ホーム画面に追加して使う)
- 期限が近いもの・数が足りないものは、ボタンで答えるまで毎日「対応待ち」に出る

## 使い方

1. iPhoneのSafariでページを開き、共有ボタン →「ホーム画面に追加」
2. 右下の「＋」で品を登録する
3. 「対応待ち」に出たものに、ボタンで答える
4. ときどき「設定 → 書き出す」でバックアップを取る

### 毎日自動で開く(任意)

「ショートカット」アプリのオートメーションで、決まった時刻やアラーム停止をきっかけに
このアプリを開くようにすると、見に行かなくても対応待ちが目の前に出る。

## 今できること(v0.5.0)

- 品の登録・編集・削除(品名、ジャンル、個数、単位、最低個数、賞味期限、使用期限、見直し日、置き場所、メーカー、型番、サイズ、メモ)
- 期限が近い順の一覧、検索、ジャンル絞り込み、＋/−で個数変更
- 対応待ち(期限・在庫不足・見直し日・バックアップ)と「また聞いて」(明日/3日後/1週間後)
- まとめ名ごとの合計と置き場所別の内訳(例:水 合計32L(押し入れ 24L・防災袋 8L))。ml→L、g→kg は自動で換算
- 入力途中の下書き保存(別のアプリから戻って入力が消えていても、続きから書ける)
- 買い物の印(買いたい/もう買わない+理由)。「買いたい」で絞り込めば買い物リストになる
- 一覧の絞り込み(ジャンル・置き場所・買い物の印・合計の行をタップ)。合計は絞り込んだ品だけで出る
- 「備え」タブ: 避難先 × 季節 × 災害を選ぶと、必要リストと持ち物を突き合わせて、達成率と足りない物を出す。
  必要リストはアプリの中で足し引きでき、人数・日数は設定で変えられる
- 「この品をコピー」(期限ちがいの同じ品を足すとき用)。同じ名前の品は一覧で一行にまとまる
- 「もう買わない」の品に似た品を入れようとすると注意が出る。品名の入力には登録済みの品名の候補が出る
- よみがな(入れると、漢字の品名も五十音順に並び、ひらがなで検索できる)
- ジャンルの追加・名前の変更・並べ替え・削除(設定タブ。最初の4つは消せない)
- 書き出し・読み込み(JSON)

## 必要リストの初期データ

`docs/requirements.initial.json` を直したら、`node tools/requirements-to-js.js` で `requirements-default.js` を作り直す(アプリは外部から何も読み込まないので、スクリプトに埋め込んでいる)。

## 注意

- 書き出したバックアップをこのリポジトリに入れないこと(`.gitignore` 済み)
- アプリのURLが変わると、端末内のデータは新しいURLからは見えない。引っ越すときは「書き出す → 読み込む」
