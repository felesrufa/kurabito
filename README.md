# kurabito

備蓄と日用品の在庫番。蔵人(くらびと)。

- **データは端末の中だけ。** アカウント登録なし、サーバーなし、外部への送信なし
- **個数制限なし・課金なし**
- **電波がなくても開ける**(ホーム画面に追加して使う)
- 期限が近いもの・数が足りないものは、ボタンで答えるまで毎日「対応待ち」に出る

## 使い方

1. iPhoneのSafariでページを開き、共有ボタン →「ホーム画面に追加」
2. 右下の「＋」で品を登録する
3. 「対応待ち」に出たものに、ボタンで答える
4. ときどき「設定 → 書き出す」でバックアップを取る

### 毎日自動で開く(任意)

「ショートカット」アプリのオートメーションで、決まった時刻やアラーム停止をきっかけに
このアプリを開くようにすると、見に行かなくても対応待ちが目の前に出る。

## 今できること(v0.1)

- 品の登録・編集・削除(品名、ジャンル、個数、単位、最低個数、賞味期限、使用期限、見直し日、置き場所、メーカー、型番、サイズ、メモ)
- 期限が近い順の一覧、検索、ジャンル絞り込み、＋/−で個数変更
- 対応待ち(期限・在庫不足・見直し日・バックアップ)と「また聞いて」(明日/3日後/1週間後)
- 書き出し・読み込み(JSON)

## 注意

- 書き出したバックアップをこのリポジトリに入れないこと(`.gitignore` 済み)
- アプリのURLが変わると、端末内のデータは新しいURLからは見えない。引っ越すときは「書き出す → 読み込む」
